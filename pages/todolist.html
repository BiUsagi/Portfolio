Giới thiệu Sou-Todo - Ứng dụng Quản lý Công việc

Sou-Todo là ứng dụng web giúp người dùng quản lý công việc cá nhân một cách hiệu quả, hỗ trợ đăng nhập, phân loại trạng thái và theo dõi tiến độ công việc.

Dự án được xây dựng với mục tiêu rèn luyện kỹ năng lập trình web fullstack, quản lý trạng thái, xác thực người dùng và tối ưu trải nghiệm thực tế.

Mã nguồn: https://github.com/BiUsagi/todo-list

Giao diện chính của ứng dụng ToDoList

Chức năng nổi bật

  • Đăng ký, đăng nhập, xác thực người dùng (Laravel Breeze)
  • Thêm, sửa, xóa, đánh dấu hoàn thành công việc
  • Lọc công việc theo trạng thái: Cần làm, Đang làm, Hoàn thành
  • Thống kê số lượng công việc theo từng trạng thái
  • Quản lý deadline, mô tả chi tiết cho từng công việc
  • Giao diện hiện đại, responsive trên mọi thiết bị

Kỹ thuật & Thư viện sử dụng

  • Backend: Laravel (PHP), Eloquent ORM, Laravel Breeze
  • Frontend: Blade template, Bootstrap 5, Font Awesome, jQuery
  • Database: MySQL
  • Quản lý mã nguồn: Git, Github

Kinh nghiệm đạt được

  • Thành thạo quy trình xây dựng ứng dụng web fullstack
  • Thiết kế giao diện responsive với Bootstrap
  • Quản lý mã nguồn hiệu quả với Git
  • Làm việc với framework Laravel, tích hợp frontend-backend

Vai trò cá nhân

  • Phân tích, thiết kế chức năng và cơ sở dữ liệu
  • Phát triển toàn bộ giao diện, logic xử lý và xác thực
  • Tối ưu UX/UI, xử lý lỗi và bảo mật
