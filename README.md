# Portfolio - Sơn

Đây là website portfolio cá nhân của Sơn, giới thiệu về bản thân, kỹ năng, các dự án đã thực hiện và thông tin liên hệ. Website được xây dựng với mục tiêu trình bày chuyên nghiệp các sản phẩm cá nhân, nổi bật là dự án **FitnessOnline** - nền tảng hỗ trợ tập thể dục tại nhà.

---

## 🚀 Demo

Truy cập website: [https://biusagi.github.io/Portfolio/](https://biusagi.github.io/Portfolio/)

---

## 🌟 Tính năng nổi bật

- Giới thiệu bản thân, kỹ năng, kinh nghiệm làm việc.
- Trình bày các dự án tiêu biểu, hình ảnh minh họa, mô tả chi tiết.
- Thông tin liên hệ nhanh chóng.
- Responsive, hiển thị tốt trên nhiều thiết bị.
- Hiệu ứng động mượt mà với CSS Animation, AOS, Owl Carousel, Magnific Popup.

---

## 💡 Dự án tiêu biểu: FitnessOnline

- Nền tảng tập luyện thể hình trực tuyến.
- Cho phép người dùng đăng ký khóa tập, theo dõi tiến độ, đánh giá khóa học.
- Huấn luyện viên có thể tạo, quản lý khóa tập và theo dõi học viên.

---

## 🛠️ Công nghệ sử dụng

- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** PHP (Laravel), JavaScript
- **Cơ sở dữ liệu:** MySQL
- **Quản lý phiên bản:** Git, Github
- **API & AJAX:** Giao tiếp dữ liệu nhanh, không tải lại trang
- **Tối ưu hóa:** Lazy load hình ảnh, phân trang, loading UI mượt
